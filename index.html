⚙ Status API Claude

Fitur AI membutuhkan Claude API Key dari Anthropic. Key tersimpan aman di browser kamu saja, tidak dikirim ke server lain.

📚 Cara Pakai
1
Daftar di Anthropic
Buka console.anthropic.com → buat akun gratis → buat API key.
2
Masukkan API Key
Klik tombol "Set API Key" di atas, tempel key kamu, lalu simpan.
3
Pilih Fitur & Gas Belajar!
Buka sidebar lewat tombol garis tiga di pojok kiri atas, pilih fitur yang kamu mau.
